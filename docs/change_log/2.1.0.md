# Change Log

Huge change in this version like some rewrite code and add bunch of new feature, here for the detail.

## Hand Caster
Same feature like version 1.x.x but has huge improvement.

**Example**
> File Location: plugins/ItemCaster/hand/example.yml

```yaml

example:
  Display: Example
  Conditions:
  - hasAura{aura=Example} true
  Abilities:
  - skill: SummonSkeleton
    activator: LEFT_CLICK

```

**Display**
> For now this is doest have any feature yet but this will be useful for ui in menu or namming the skillsets

**Conditions**
> Same feature as Conditiions in skill. you can use it for player can use the skillsets when holding/has attribute/etc.

**Abilities**
> Main core of this hand skill activator. same as Item Skill Attributes
