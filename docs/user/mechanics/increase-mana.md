!!! note
    If you have plugin like `AuraSkills` or other plugin that has mana and supported in ItemCaster. this mechanic will be enabled

## Attributes

| Attribute | Aliases | Description | Default |
|-----------|---------|-------------|---------|
| `amount`  | `a`     |             | `1.0`   |

## Example
```yaml
Skills:
- increasemana{a=>10} true
```
