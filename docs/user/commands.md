# Commands

Commands & Aliasses:

- itemcaster
- ic

- itemcastermenu
- icm

- handcastertoggle
- hct

## /ic reload
> Aliasses: /ic r

Send a message to use `/mm r` instead, because this plugin is an add-on of MythicMobs.

## /ic menu
> Aliasses: /ic m

Open the menu editor.

## /ic hand
> Aliasses: /ic h

Command section for HandCaster.

## /ic hand set <ability\> [target]
> Aliasses: /ic h s

Set target ability.

## /ic hand remove [target]
> Aliasses: /ic h r

Remove target ability.

## /ic profile
> Aliasses: /ic p

Player data section.

## /ic profile save [target]
> Aliasses: /ic p s

Save the player target data.

## /ic profile saveall
> Aliasses: /ic p sa

Save all online player data.
